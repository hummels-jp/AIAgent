# Stock Dashboard 操作手册

> 项目目录：`D:\huqianqian_git\AIAgent\20260402_stock`
> 架构：**OpenD（富途）** ⇄ **Python (futu_service.py)** ⇄ **Node (server.js : 3000)** ⇄ **前端 index.html**

---

## 一、系统架构图

```
┌─────────────────┐    WebSocket    ┌──────────────────┐   subprocess   ┌─────────────────┐    HTTP    ┌──────────────┐
│  FutuOpenD.exe  │ ◄────────────► │ futu_service.py  │ ◄────────────► │   server.js     │ ◄────────► │  index.html  │
│   127.0.0.1     │   port 11111   │  (futu-api SDK)  │     stdin/out  │  Express :3000  │   /api/*   │   (浏览器)   │
└─────────────────┘                └──────────────────┘                └─────────────────┘            └──────────────┘
```

- **OpenD**：富途桌面客户端，负责连接行情/交易服务器，对外开放本地 API 端口
- **Python**：用 futu-api SDK 真正调用 OpenD，把数据 `print` 成 JSON
- **Node**：Express 服务器，被前端请求时 `spawn` 一次 Python 拿数据
- **前端**：纯静态 `index.html`，调 `http://localhost:3000/api/*`

## 二、启动顺序（**必须严格按这个顺序**）

> 任何一步失败都会导致后面失败。

### Step 1 — 启动并配置 OpenD

**方式 A：手动启动（推荐，方便看登录窗口）**

1. 双击桌面或开始菜单的 **「富途 OpenD」**
2. 等待 OpenD 主界面弹出
3. **登录富途账号**（手机号 + 密码 + 短信验证码）
4. **确认 API 端口 = 11111**
   - 看 OpenD 主界面右下角或「设置」→「API 设置」
   - 如果端口不是 11111：
     - 改 OpenD 端口为 `11111`（推荐，代码全用 11111）
     - 或反过来改代码（见第六章）
5. **点击「解锁交易」按钮** ⚠️
   - 输入 **交易密码（6 位）**
   - 不解锁 → `/api/positions` 持仓接口必失败

**方式 B：脚本启动（OpenD 路径默认）**

```cmd
D:\huqianqian_git\AIAgent\20260402_stock\start_opend.bat
```

> 该脚本会用 `-websocket_port 11111` 启动 OpenD。登录 + 解锁交易仍需手动完成。

---

### Step 2 — 启动 Node API 服务器

打开 **新的** cmd 窗口（OpenD 那个不要关）：


## 四、常见错误对照表

### 错误 1：「获取当前持仓数据失败」

| 可能原因 | 排查 | 解决 |
| --- | --- | --- |
| OpenD 没启动 | 任务管理器看 `FutuOpenD.exe` | 启动 OpenD |
| 端口不匹配 | OpenD 实际端口 ≠ 11111 | 改 OpenD 端口为 11111；或改代码（见第六章） |
| **交易未解锁** ⭐最常见 | OpenD 界面「解锁交易」按钮还亮着 | **点击「解锁交易」，输交易密码** |
| 富途账号没登录 | OpenD 主界面是登录窗 | 输入账号密码登录 |
| Node 服务没重启 | Node 启动时间早于 OpenD | 关掉 Node 黑窗口，重新 `npm start` |

### 错误 2：「使用模拟数据：3 条」

`server_log.txt` 里出现：
```
[API] ⚠ 调用 Python 失败: JSON 解析失败:
       Unexpected non-whitespace character after JSON at position 4
```

→ 已在 `server.js` 第 117-140 行修过，确保用的是 **取最后一个可解析 JSON 行** 的版本。若仍报错，去 `server\` 目录手动跑：

```cmd
python futu_service.py --action today --market HK
```

看最后一行是不是 **完整且唯一** 的 JSON。如果不是，把整段输出贴给我。

### 错误 3：「无法启动 Python」

```
[FutuService] 无法启动 Python: spawn python ENOENT
```

→ Python 不在系统 PATH。在 cmd 跑：

```cmd
python --version
```

不通的话装 Python 3.10+ 并勾选 "Add to PATH"，或修改 `server.js:103` 的 `pythonCmd`。

### 错误 4：端口 3000 被占用

```
Error: listen EADDRINUSE: address already in use :::3000
```

→ 之前的 Node 服务没退干净。

```cmd
netstat -ano | findstr :3000
taskkill /PID <pid> /F
```

## 七、API 端点列表

| 端点 | 用途 | Python action |
| --- | --- | --- |
| `GET /api/health` | 服务健康检查 | — |
| `GET /api/check-port` | 检测 OpenD 端口是否可达 | — |
| `GET /api/hot-sectors` | 热门板块 | `hot-stocks` |
| `GET /api/trade-history?period=today&market=HK` | 交易记录（today / 1w / 1m） | `today` 等 |
| `GET /api/positions` | 持仓（需解锁交易） | `positions` |
| `GET /api/vix` | VIX 指数 | `vix` |
| `GET /api/watchlist` | 自选股 | `watchlist` |
| `GET /api/stock-changes` | 股票异动 | `stock-changes` |

> period: `today` / `1w` / `1m`
> market: `HK` / `US`

## 八、关闭顺序

1. 浏览器关掉前端页面
2. Ctrl+C 关掉 Node 黑窗口
3. OpenD 右键托盘图标 → 退出（**记得退出 OpenD 才会断开服务器连接，避免占用席位**）
