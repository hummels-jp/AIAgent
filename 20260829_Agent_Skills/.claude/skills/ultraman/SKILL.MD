# Ultraman 场景描述生成器

## 描述
根据用户指定的输入（角色、怪兽、场景、动作、氛围等），生成结构化的 Ultraman 系列特摄场景描述语言。适用于剧本分镜、小说描写、AI 绘图提示词、视频分镜等场景。

## 使用方式
用户提供一个或多个场景要素，模型按照约定的格式输出一段或多段场景描述。

## 输入参数
用户提供以下任意字段，字段缺失时由模型自行补全合理设定：

| 字段 | 说明 | 示例 |
|------|------|------|
| `奥特曼` | 登场的奥特英雄 | 赛罗奥特曼、迪迦奥特曼、泽塔奥特曼 |
| `形态/变身器` | 当前形态或使用的变身道具 | 闪耀型、阿尔法利刃、贝塔粉碎 |
| `怪兽/宇宙人` | 敌对角色 | 杰顿、巴尔坦星人、贝利亚 |
| `场景地点` | 战斗或事件发生的场所 | 城市废墟、宇宙空间、海底基地 |
| `时间/天气` | 时段与气象 | 黄昏、雷雨夜、黎明 |
| `动作/事件` | 核心动作或剧情节点 | 登场、变身、发射光线、城市保卫战 |
| `氛围/情绪` | 画面基调 | 悲壮、热血、悬疑、压迫感 |
| `镜头/视角` | 拍摄/描述视角 | 仰拍、俯视、跟拍、特写 |
| `特效需求` | 需要强调的视觉特效 | 粒子光效、爆炸、建筑倒塌 |

## 输出格式
每一段场景描述包含以下结构化内容：

1. **场景标题**：一句话概括该场景。
2. **环境描写**：地点、时间、天气、整体氛围。
3. **角色登场**：奥特曼与怪兽的姿态、位置、动作。
4. **动作细节**：具体战斗或剧情动作，包含招式名称、特效表现。
5. **光影与镜头**：光线变化、镜头运动、视觉焦点。
6. **情绪渲染**：场景传递的情感或主题。
7. **可选：分镜建议**（如用户需要）：画面构图、景别、运镜。
8. **AI 绘图提示词**（必须）：英文 tag 形式，用于后续生成图像。

## 示例

### 输入
```
奥特曼：迪迦奥特曼
形态：复合型
怪兽：加坦杰厄
场景地点：太平洋海底遗迹

动作/事件：最终决战，发射哉佩利敖光线
氛围/情绪：悲壮、绝望中的希望
镜头/视角：仰视巨大邪神与渺小英雄
特效需求：光线穿透黑雾、海面漩涡、遗迹崩塌
```

### 输出
**场景标题**：黑雾尽头的光之决战

**环境描写**：
太平洋海底的远古遗迹在永恒的黄昏中沉寂，海水被加坦杰厄的黑暗力量搅动成巨大漩涡。天空被厚重的黑云遮蔽，仅存的几缕光线从云缝中垂落，照在迪迦屹立不倒的身躯上。

**角色登场**：
复合型迪迦半跪在断裂的石柱旁，胸口的彩色计时器急促闪烁；对面，加坦杰厄如山峦般盘踞，无数触手从黑雾中探出，巨眼散发出令人窒息的恶意。

**动作细节**：
迪迦双手在胸前交叠，凝聚出耀眼的白色光球——哉佩利敖光线。他猛地推出双臂，光线划破黑雾，直击加坦杰厄的躯体。邪神发出震耳欲聋的咆哮，触手疯狂挥舞，遗迹的石块纷纷坠落。

镜头从海底仰视，迪迦的身躯在逆光中成为希望的剪影；哉佩利敖光线的轨迹照亮整片海域，黑雾被撕裂的瞬间，画面转为高对比度的明暗交界。

**情绪渲染**：
这是绝望深渊中最后的抗争，微光不屈地穿透黑暗，象征着人类与奥特曼共同守护的信念。

## 图片生成工作流

每完成一段场景描述后，必须立即调用图片生成脚本，根据刚刚生成的 **AI 绘图提示词** 生成对应图片，并保存到 `./images` 目录下。

### 步骤

1. **生成英文提示词**：在场景描述末尾输出 `AI 绘图提示词` 代码块（英文 tag 形式）。
2. **构建图片文件名**：使用当前日期时间命名，格式为 `ultraman_<YYYYMMDD>_<HHMMSS>.png`，例如 `ultraman_20260829_143052.png`。
3. **调用生成脚本**：执行

   ```bash
   python .claude/skills/ultraman/scripts/generate_image.py \
       --prompt "<上一步生成的英文提示词>" \
       -o ./images/ultraman_<YYYYMMDD>_<HHMMSS>.png
   ```

   如果场景描述已保存到文件，也可使用 `--scene <文件路径>` 让脚本自动提取提示词。
4. **输出结果**：向用户报告生成的图片保存路径。

### 示例调用

```bash
python .claude/skills/ultraman/scripts/generate_image.py \
    --prompt "Ultraman Tiga, Multi Type, glowing eyes, Zeperion Beam, golden light ray piercing dark fog, underwater ancient ruins, giant evil god Gatanothor, tentacles, whirlpool, dramatic sunset lighting, cinematic composition, low angle shot, particles, splash, epic battle, tokusatsu style" \
    -o ./images/ultraman_20260829_143052.png
```

### 注意

- `./images` 目录不存在时，脚本会自动创建。
- 图片生成依赖 `config.json` 中的 API Key。首次使用请复制 `config.example.json` 为 `config.json` 并填写你的 OpenRouter API Key。
- 部分文生图提供商会拦截包含版权/商标名称（如具体奥特曼角色名）的提示词。若遇到 400 错误，可在 `AI 绘图提示词` 中使用描述性表达（如 “silver and orange armored giant hero”）替代商标名称。
- 若用户明确说“不要生成图片”，则跳过此步骤。

## 约束与风格
- 描述语言应具有特摄片的画面感与节奏感，避免过于抽象。
- 招式、形态、怪兽名称优先使用官方中文译名。
- 根据输入字段的完整度自动调整输出详略。
- 若用户未指定奥特曼系列，默认基于圆谷制作的《奥特曼》系列世界观生成。
- 保持积极向上的基调，避免过度血腥或恐怖描写。
